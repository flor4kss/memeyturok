# 🎭 Telegram Meme, AI & Animation Userbot

Мощный Telegram-юзербот для генерации мемов, диалогов с AI-персонажами (Groq Llama 3.3), анимации текста и шитпостов прямо в любых переписках.

---

## 🧠 AI-Персонажи и Нейросеть (Groq Llama 3.3)

Ответьте командой на сообщение собеседника или задайте вопрос напрямую:

| Команда | Персонаж / Роль | Пример ответа |
| :--- | :--- | :--- |
| **`.патрик <вопрос>`** | ⭐️ **Патрик Стар** (глупый, наивный, думает о еде и камнях) | `⭐️ Патрик: Я не слышал вопрос, потому что думал о крабсбургере...` |
| **`.стоун <вопрос>`** | 🧪 **Сэнку (Dr. Stone)** (гениальный ученый, физика, химия) | `🧪 Сэнку: Это на 10 миллиардов процентов научно доказуемо!` |
| **`.стэтхем <вопрос>`** | 🐺 **Джейсон Стэтхем** (пацанские цитаты из ВК) | `🐺 Стэтхем: Кто рано встает — тот не я, брат.` |
| **`.гопник <вопрос>`** | 🧢 **Пацанчик с района** (дворовой сленг) | `🧢 Пацанчик: Слышь, ты чё за предъявы кидаешь, обоснуй по фактам!` |
| **`.бабка <вопрос>`** | 👵 **Бабка у подъезда** (ворчит, все наркоманы) | `👵 Бабка: Ишь чего захотели! Интернетов своих обсмотрелись!` |
| **`.кратко`** | 📋 **Краткая суть (TL;DR)** | Выжимка сути из длинного текста в 1–2 предложения |
| **`.ии <вопрос>`** | 🤖 **AI-Ассистент** | Умный ответ на любую тему / код / решение задач |

### 🤫 Чистый режим (Скрытый / Stealth mode):
Если добавить дефис в конце команды (например: **`.патрик-`**, **`.стоун-`**, **`.ии-`**), юзербот отправит **чистый текст** без рамок и плашек, будто это написал ты сам!

## ⌨️ Текстовая анимация и утилиты

| Команда | Описание |
| :--- | :--- |
| **`.тайп <текст>`** | Живая печатная машинка: текст побуквенно печатается в чате с курсором `▌` |
| **`.взлом <цель>`** | Анимированный голливудский взлом с прогресс-баром и процентами |
| **`.сердце`** | Переливающаяся анимация сердец всех цветов |
| **`.р`** | Автоматическое исправление раскладки (в ответ на `ghbdtn rfr ltkf`) |

---

## 🖼 Мем-генераторы (ответьте на картинку)

| Команда | Описание |
| :--- | :--- |
| **`.м <текст>`** | Классический мем со шрифтом **Impact** (можно `.м СВЕРХУ; СНИЗУ`) |
| **`.дем <заголовок>; <подзаголовок>`** | Классический демотиватор 2000-х с рамкой и шрифтом Times |
| **`.волк <цитата>; <автор>`** | Ч/Б волчья цитата с темной виньеткой |
| **`.новости <текст>`** | Плашка «СРОЧНЫЕ НОВОСТИ» снизу как по ТВ |
| **`.шакал` / `.дипфрай`** | Адская прожарка контраста и артефактов |
| **`.бабл`** | Спич-бабл (облако мыслей) над головой |
| **`.лево` / `.право`** | Симметрия лица (зеркалит левую или правую половину) |
| **`.рип`** | Ч/Б траурный портрет с лентой |

## ☁️ Деплой на Render (24/7)

1. Загрузите файлы в репозиторий GitHub.
2. В Render Web Service добавьте Environment Variables:
   - `SESSION_STRING` = `<строка из session_string.txt>`
   - `GROQ_API_KEY` = `<бесплатный ключ с console.groq.com>` *(опционально для макс. скорости)*
   - `PORT` = `8080`
3. Нажмите **Manual Deploy**.
