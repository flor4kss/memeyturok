# 🎭 Telegram Meme Bot (Генератор мемов по реплаю)

Telegram-бот, который превращает любую картинку в классический мем со шрифтом **Impact** (белый текст с жирным черным контуром, автоперенос строк, поддержка кириллицы и латиницы).

---

## 🚀 Как работает бот

1. **В личных сообщениях с ботом:**
   - Отправьте картинку с подписью (*caption*).
   - Или отправьте картинку, а затем ответьте на неё реплаем с текстом.
2. **В беседах / групповых чатах:**
   - Ответьте на любую картинку (Reply):  
     `@имя_бота Текст мема`
3. **Разделение на верхний и нижний текст:**
   - Если написать `ТЕКСТ СВЕРХУ; ТЕКСТ СНИЗУ` (через точку с запятой `;` или перенос строки `\n`), то первая часть будет сверху, а вторая — снизу.
   - Если разделителя нет, текст автоматически разместится снизу.

## 🛠 Шаг 1: Создание бота в Telegram

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Введите имя бота (например, `Super Meme Bot`) и юзернейм (например, `my_cool_meme_bot`).
3. Скопируйте полученный **API Token** (вида `1234567890:ABCdef...`).
4. ⚠️ **КРИТИЧЕСКИ ВАЖНО ДЛЯ ГРУППОВЫХ ЧАТОВ:**
   - В диалоге с `@BotFather` отправьте команду `/setprivacy`.
   - Выберите вашего бота.
   - Нажмите **Disable** (это позволит боту видеть сообщения с упоминанием и реплаи на картинки в группах).
   - Включите группы: `/setjoingroups` $\to$ **Enable**.

## ☁️ Шаг 2: Бесплатный деплой на Render.com

[Render.com](https://render.com) позволяет бесплатно хостить приложения в облаке.

### Вариант через GitHub (Рекомендуемый):

1. Загрузите этот проект в свой репозиторий на **GitHub**.
2. Зарегистрируйтесь / войдите на [Render.com](https://dashboard.render.com).
3. Нажмите **New +** $\to$ **Web Service**.
4. Подключите ваш GitHub-репозиторий с ботом.
5. Заполните настройки:
   - **Name**: `telegram-meme-bot` (любое имя)
   - **Language / Environment**: `Python` (или `Docker`)
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python -m bot.main`
   - **Instance Type**: `Free`
6. В разделе **Environment Variables** (Переменные окружения) добавьте:
   - `BOT_TOKEN` = `ваш_токен_от_BotFather`
   - `PORT` = `8080`
7. Нажмите **Create Web Service**.

> 💡 *В проект уже встроен фоновый HTTP health-check сервер, поэтому Render сразу определит сервис как работающий и не будет выдавать ошибок порта.*

## 💻 Локальный запуск на компьютере

Если вы хотите запустить бота у себя на ПК:

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте файл `.env` (скопировав из `.env.example`):
   ```env
   BOT_TOKEN=ваш_токен_от_BotFather
   ```
3. Запустите бота:
   ```bash
   python -m bot.main
   ```
