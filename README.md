# 🎭 Telegram Meme Userbot & Bot

Мощный Telegram-юзербот для мгновенного превращения картинок в мемы, демотиваторы, цитаты и шитпосты прямо в любых переписках.

---

## ⚡️ Список доступных команд

Просто ответьте (Reply) на любую картинку/фото одной из команд:

| Команда | Что делает | Пример |
| :--- | :--- | :--- |
| `.м <текст>` | Классический мем со шрифтом **Impact** | `.м КОГДА КОД ЗАРАБОТАЛ` или `.м ТЕКСТ СВЕРХУ; ТЕКСТ СНИЗУ` |
| `.дем <заголовок>; <подзаголовок>` | Классический демотиватор 2000-х с рамкой | `.дем СТАБИЛЬНОСТЬ; Это когда ты снова опоздал` |
| `.волк <цитата>; <автор>` | Пацанская цитата / Стэтхем в Ч/Б | `.волк Безумно можно быть первым; Ауф` |
| `.новости <текст>` | Плашка «СРОЧНЫЕ НОВОСТИ» снизу как по ТВ | `.новости ЭТОТ ЧЕЛОВЕК СЪЕЛ ВСЕ ПЕЛЬМЕНИ` |
| `.шакал` / `.дипфрай` | Адская прожарка контраста и артефактов (Shitpost) | `.шакал` |
| `.бабл` | Диалоговое облако (Speech Bubble) над головой | `.бабл` |
| `.лево` | Симметрия левой половины лица (инопланетное лицо) | `.лево` |
| `.право` | Симметрия правой половины лица | `.право` |
| `.рип` / `.rip` | Ч/Б фото с траурной лентой «Помним... Любим...» | `.рип` |

> 💡 *Все эти команды работают как для вас, так и для ваших друзей в личных сообщениях!*

## ☁️ Деплой на Render (24/7)

1. Загрузите файлы в репозиторий GitHub.
2. В Render Web Service добавьте Environment Variable:
   - `SESSION_STRING` = `<строка из session_string.txt>`
   - `PORT` = `8080`
3. Нажмите **Deploy**.
